01 / DEVICE GUIDE

Root your XP3800.

Start here if Wave sent you to the device guide. With Chrome or Edge and a USB data cable, this site roots the phone with Magisk 24.0 and keeps a copy of its stock boot image on your computer. It can also check compatibility, read a backup on its own, put the stock image back, and disable a broken module with Rescue.

Root this phone from the browser

The rooting page saves your stock boot image to this computer, patches it on the phone with Magisk 24.0’s own tools, writes it over Qualcomm EDL and checks every byte, then installs the Magisk app and Wave. It writes only the boot partition, and only after your backup is saved and checked. Stock boot puts the saved image back. Tested on one XP3800 with Chromium on Linux.

Only read a boot backup

To keep a backup without rooting, the backup page reads the phone’s boot partition twice, compares the copies and saves the image with a manifest. It only reads. Then verify the saved files. Linux may need a driver detached first: see the USB guide.

Check this phone

  1. Open Settings → About phone and select Build number seven times with the center key.
  2. In Settings → Developer options, turn on USB debugging.
  3. Connect only this phone with a USB data cable. Close desktop adb and other tools that may already hold its USB interface.

Use Chrome or Edge on a secure page for the USB check. The rest of the guide works without WebUSB.

What the rooting page does, and why

  1. Backup first. It finds boot by name in the partition table and refuses a layout that isn’t an XP3800’s, reads it twice and compares the 32 MiB copies, and checks its stock signature. You save the image and choose the saved file again, so the page knows the copy on your disk is whole. Back up contacts, messages and other personal data separately: a boot image is not a copy of your files.
  2. Patch on the phone. Magisk 24.0’s ARM tools and boot_patch.sh run on the phone as the USB debugging user, and Magisk’s own SignBoot signs the result. The XP3800 refuses an unsigned boot image (it shows the Sonim logo and goes black), so the page checks the signature in the browser, against the same certificate as your stock image, before anything is written.
  3. Write and verify. In EDL (05c6:9008; 05c6:900e is crash-dump mode) the page first requires boot to still equal your backup, writes the patched image, then reads the whole partition back and compares it. If that comparison fails it writes your stock image straight back.
  4. Root is yours to give. Magisk asks on the phone. The page asks once for USB debugging (for Rescue), and only if you choose to. Wave gets no root until it asks Magisk itself, when you first install a mod.

Never use another phone’s boot image, even the same model and carrier. Nothing on this site writes to /system or touches bootloader flags. If Android is unavailable, follow the cold-start checks to reach EDL, and see the USB guide if permissions or drivers prevent a connection.

Already rooted?

Install Wave from Wave releases. Ordinary APKs install without root. For system mods, choose Wave → Root for System Mods → Check Again and answer the Magisk prompt on the phone. A denied Shell request can be a Magisk Superuser access setting rather than a broken boot image.

If Android still answers adb but a module broke the launcher, try Rescue. If Android does not start, put the stock image back with Stock boot.
