02 / MODULE RECOVERY

Disable a broken module.

Rescue is for a rooted Sonim XP3800 that still connects through Android USB debugging. It turns off selected modules for the next boot without uninstalling them.

Check installed modules

Connect only the affected XP3800. Approve the USB debugging fingerprint on the phone, then grant the shell one-time root access in Magisk if prompted. Rescue does not change superuser policy.

For the USB tool, open this page securely in Chrome or Edge.

Enabled modules

When the browser cannot connect

Try Magisk’s safe-mode key gesture first: hold Volume Down for three seconds during startup. Magisk can disable its modules before Android starts. The gesture has not been verified on this XP3800 build.

If the phone reaches Android but Rescue is denied, check Magisk → Settings → Superuser access and the shell’s permission. The browser cannot authorize itself. If Android will not boot at all, see Restore for stock recovery instead.
