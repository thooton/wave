06 / BACK TO STOCK

Write the stock boot image back.

This removes root by writing your phone’s own saved stock boot image over EDL, then reads the whole partition back and requires it to match byte for byte. Use it if the phone won’t start after rooting, or to unroot.

Use only this phone’s own backup. An image from another phone, even the same model, can stop it from starting. The page accepts only a full 32 MiB image with the XP3800’s stock signature and no Magisk patch, and needs its manifest or its SHA-256 from when you saved it. Writing stock boot does not remove the Magisk app, Wave, their data or /data/adb.

1. Choose the files

Only the pinned file (SHA-256 e6f2dbcf…2767) is accepted. 





2. Get the phone into EDL


If Android starts, connect it with USB debugging on: the page checks its serial and build against the manifest and restarts it into EDL.




If it doesn’t start, use the cold start: battery out for 30 seconds, hold both volume keys while you refit it and plug in USB. Only 05c6:9008 is EDL.





3. Write and verify


The page reads boot first and offers that copy for download, writes the stock image, reads all 32 MiB back and compares, then restarts Android.





Save what boot held before




Afterwards, uninstall the Magisk app from Android’s Settings if you don’t want it. To root again, use Root.
