04 / READ-ONLY BACKUP

Back up your XP3800’s boot partition.

This optional tool reads the partition table and boot twice, checks that both reads match, then requests a return to Android. No partition is written. Files and device details stay on this computer.

1. Record this phone’s identity

With Android running and USB debugging enabled, connect only this phone. Use the USB check, or enter the Android USB serial and full build fingerprint from your existing device records. EDL itself cannot verify the Android identity. Neither method proves that an image is stock.

2. Connect the same phone in EDL

Charge it to at least 40%, then enter EDL using your normal service procedure. The correct USB ID is 05c6:9008; 05c6:900e is crash-dump mode. See EDL entry and cold-start checks and the USB and driver guide.

Use your own verified copy. The page accepts only the pinned XP3800 programmer and does not supply or upload this file.

Use Chromium or Chrome on Linux over HTTPS or a loopback connection. This workflow has not been tested on other platforms.
