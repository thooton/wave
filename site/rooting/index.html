05 / ROOT FROM THE BROWSER

Root your XP3800 with Magisk 24.0.

This page saves your stock boot image to this computer, patches it on the phone with Magisk 24.0, writes it back over Qualcomm EDL, and installs the Magisk app and Wave. Each step checks the one before it. Nothing is written until your backup is saved and checked.

This writes your phone’s boot partition. Only the boot partition is changed. A mistake there stops Android from starting until the stock image is written back, which needs a cold EDL start (battery out). Keep the saved backup. Charge the phone to at least 40% first and use a data cable you trust. Tested on Linux with Chromium only.

JavaScript and WebUSB (Chrome or Edge, on a secure page) are needed.

1. Choose the files

The page checks each file against its published SHA-256 before using it. These stay in your browser; nothing is uploaded.

Your own verified copy, for example from the community XP3800 project. Only the pinned file (SHA-256 e6f2dbcf…2767) is accepted.
The official v24.0 release, SHA-256 f7ac4e2a…346a. Other versions are refused.
From Wave releases. It is installed with Android’s package manager.

2. Connect the phone

  1. On the phone, open Settings → About phone and select Build number seven times, then turn on Developer options → USB debugging.
  2. Connect only this phone. Stop desktop adb first (adb kill-server).
  3. Approve “Allow USB debugging?” on the phone. Leave “Always allow” off.

The page checks the model, Android version, battery and that the phone has no root yet, then restarts it into EDL.

3. Read the stock boot image

The phone’s screen stays dark in EDL. Choose Qualcomm … 9008 in the USB chooser (05c6:9008; 05c6:900e is crash-dump mode and won’t work). On Linux a kernel driver may hold the device: see the USB guide. The page reads boot twice, checks the copies match and carry the stock signature, then restarts Android.

4. Save the backup

Save both files somewhere outside the phone, then choose the saved image so the page can check the copy on your disk. Keep a second copy offline. This is the only way back to stock.

Save boot imageSave manifest JSON

5. Patch on the phone

Wait for Android to start, then connect it again (approve USB debugging if asked). The page copies Magisk 24.0’s own ARM tools to /data/local/tmp, runs Magisk’s boot_patch.sh on your stock image, signs the result with Magisk’s SignBoot, and checks the signature in this browser. It installs the Magisk app and Wave, removes its work files, and restarts into EDL.

6. Write the patched boot

Choose the EDL device again. Before writing, the page reads boot and requires it to equal your saved backup. It writes the patched image, reads the whole partition back and compares it, then restarts Android. The first rooted start takes a little longer.

7. Finish in Magisk

Connect Android again. The page checks that Magisk started and opens the Magisk app. When it shows Requires Additional Setup, move to OK and press the center key; the phone restarts.

8. Open Wave

Optional: let USB debugging use root, which Rescue needs if a module ever breaks the phone. The page runs su once over USB and Magisk asks on the phone. Choose Forever if you want it remembered and Grant; the prompt gives up after 10 seconds. Wave itself is not given root. It asks Magisk when you first install a mod.



If something goes wrong


A failed read or a failed check before step 6 changes nothing. Restart the phone (hold the power key, or take the battery out if it stays dark) and try the step again; the page remembers where it got to. If the phone won’t start after step 6, put the stock image back from Stock boot, using the cold start to reach EDL.
