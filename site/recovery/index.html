      Can’t find device?

      Windows: You may need to install a driver for this mode. Install Zadig, choose Options › List All Devices, select QUSB__BULK (05C6 9008), and install WinUSB

      Linux: The qcserial driver may be holding the device, try sudo modprobe -r qcserial. Alternatively, udev rule may be necessary SUBSYSTEM=="usb", ATTR{idVendor}=="05c6", ATTR{idProduct}=="9008", TAG+="uaccess"

      macOS: No setup is needed

      WebUSB not available. A Chromium-based browser (Chrome, Edge, Brave, etc.) is required
