Recover your phone

Android starts, but a Magisk module broke something: turn off modules.

You want to unroot, or the phone won’t start: write your stock boot backup back.

Turn off modules

For a rooted phone that still starts Android. Connect it with USB debugging on, approve it, and grant Shell root in Magisk if asked. Modules are turned off for the next start, not removed.

Enabled modules

The page can’t connect

Hold Volume Down for three seconds while the phone starts: Magisk’s safe mode turns off modules before Android starts (not yet tried on the XP3800).

If root is denied, check Magisk › Superuser for Shell. If Android doesn’t start at all, write your stock boot back.

Choose your backup

Use only this phone’s own stock boot image, the one saved while rooting. Writing it removes root; it doesn’t remove Magisk, Wave or their data.

            The phone isn’t in the list
            
Use 05c6:9008 only (05c6:900e is crash dump: take the battery out and start again).

            
Windows: in Zadig, choose Options › List All Devices, select 05C6 9008, replace its driver with WinUSB, then reload this page.

            
Linux: allow the device with a udev rule (SUBSYSTEM=="usb", ATTR{idVendor}=="05c6", ATTR{idProduct}=="9008", TAG+="uaccess"). If it still can’t be claimed, qcserial holds it: sudo modprobe -r qcserial.

            
Close other phone tools and adb; only one program can use the phone at a time.
