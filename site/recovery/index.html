Recover your device

If an installed package broke the device, it’s recommended to turn off modules to prevent them from starting.

If you want to unroot the device, or the device won’t start, it’s recommended to write the stock backup back to the device.

Turn off modules

If your device is rooted and can still boot into Android, enable USB debugging and connect it to your computer. Approve the connection on your device, and if prompted by Magisk, grant Shell root access. Note that this process will disable modules for the next restart, but it will not remove them.

Enabled modules

The page can’t connect

Hold Volume Down for three seconds during boot: Magisk safe mode disables modules before Android starts (untested on XP3800).

If root is denied, check Magisk › Superuser for Shell. If Android doesn't start, restore your stock boot image.

Choose your backup

Use only this device's stock boot image saved during rooting. Flashing it removes root, but not Magisk, Wave, or their data.

            Can’t find device?
            
Use 05c6:9008 only. If you see 05c6:900e (crash dump), remove the battery and start again.

            
Windows: In Zadig, go to Options › List All Devices, select 05C6 9008, replace the driver with WinUSB, and reload this page.

            
Linux: Allow the device with a udev rule (SUBSYSTEM=="usb", ATTR{idVendor}=="05c6", ATTR{idProduct}=="9008", TAG+="uaccess"). If it still cannot be claimed, qcserial may be holding it: sudo modprobe -r qcserial.

            
Close other device tools and adb; only one program can use the device at a time.
