01 / DEVICE GUIDE

Prepare your XP3800.

Start here if Wave sent you to the device guide. You can check compatibility over USB, verify a saved backup and use Rescue to disable modules on a phone that already has root.

This page does not root your phone. Make the backup and perform any patching or flashing outside the browser using your own trusted XP3800 service procedure. This site can check a backup file, not create one from your phone.

Check this phone

  1. Open Settings → About phone and select Build number seven times with the center key.
  2. In Settings → Developer options, turn on USB debugging.
  3. Connect only this phone with a USB data cable. Close desktop adb and other tools that may already hold its USB interface.

Use Chrome or Edge on a secure page for the USB check. The rest of the guide works without WebUSB.

1. Back up before making changes

Back up contacts, messages and other personal data separately. A boot image is not a copy of your files. Charge the phone above 40% and record its serial and full firmware build with your backup.

Use a trusted service tool to read the GPT and locate the single boot partition by name. Read that partition twice and compare the full 32 MiB copies. A stock XP3800 image starts with ANDROID!. Save both copies offline with their original SHA-256. Never use another phone’s image, even for the same model and carrier.

Verify your boot backup

2. Know what service mode looks like

Qualcomm emergency download mode (EDL) identifies itself as 05c6:9008. 05c6:900e is crash-dump mode and cannot be used as EDL. If Android is unavailable, follow the cold-start checks. See the USB guide if permissions or drivers prevent connection.

3. Patch on the phone, not on a computer

The community procedure for the XP3800 uses Magisk 24.0 and the stock image from that same phone. PC-side patching can produce an image that shows the Sonim logo and immediately black-screens. Avoid substituting a downloaded boot image or a different Magisk version. No patching or flashing is done by this site.

If servicing the phone, verify any write byte for byte before restarting. A patched image can be shorter than the partition; compare the bytes actually written. For a stock restore, compare the entire partition. Do not write to /system or try to edit bootloader flags.

4. Check Android before installing Wave

Wait for Android to finish booting, then check that Magisk reports a working installation. Magisk handles superuser access. Review prompts on the phone and grant only to apps you trust. If the shell is denied after installing Magisk’s app, check its Superuser access setting; denial alone does not mean the boot image is broken.

Once root works, install a Wave build from Wave releases when available, then open it from the launcher. Wave will ask for root. The site does not grant root privileges or change Magisk settings.

If Android still answers adb but a module broke the launcher, try Rescue. If Android does not start, use the stock Restore guide.
