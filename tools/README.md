# tools

- `wavesrc/`: `lint` checks a source against the format; `publish` writes a
  built package's manifest and icon into a source. Python 3, standard
  library only. Also wrapped as GitHub Actions at the repo root (`lint/`,
  `publish/`). See `docs/tasks/02-wavesrc.md`.
- `sync-common.sh`: refreshes `common/` from `wave_packages`
  (`docs/tasks/04-app-foundation.md`).
